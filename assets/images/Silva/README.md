# Imagens do Projeto Silva & Associados

## Instruções

Adicione aqui a imagem de preview do projeto:

- **silva-preview.png** - Screenshot da landing page do escritório Silva & Associados

### Especificações Recomendadas

- **Formato:** PNG ou JPG
- **Dimensões sugeridas:** 1200x800px ou similar
- **Nome do arquivo:** silva-preview.png

### Como obter a imagem

1. Acesse o site: https://gipsy7.github.io/SilvaAssociadosLandingPage/
2. Tire um screenshot da página principal
3. Salve o arquivo como `silva-preview.png` nesta pasta

### Fallback

Caso a imagem não seja adicionada, o site utilizará automaticamente um placeholder.
