Visão Geral do Projeto

Petrukio é uma solução SaaS completa para gerenciamento de pet shops, clínicas veterinárias e estabelecimentos similares. Desenvolvido do zero com arquitetura full-stack moderna, implementa um sistema multi-tenant completo, permitindo que múltiplas empresas utilizem a mesma infraestrutura com total isolamento de dados.

O sistema resolve problemas reais do mercado: pet shops enfrentam dificuldades em gerenciar agendamentos manualmente, lidar com confirmações via telefone e organizar dados de clientes/pets de forma eficiente. Petrukio automatiza todo esse fluxo, reduzindo no-shows e otimizando o tempo da equipe.

Funcionalidades Principais

Multi-Tenancy Completo

Isolamento total de dados por empresa. Cada tenant tem configurações independentes (idioma, moeda, fuso horário) com registro automatizado e setup instantâneo.

KPIs em tempo real, visualização de próximos agendamentos, filtros por data e status, carregamento assíncrono otimizado com skeleton screens.

Arquitetura e Padrões

Frontend Architecture

App Router (Next.js 14) com file-based routing
├── Client Components ("use client") para interatividade
├── Custom Hooks para lógica compartilhada
│   ├── useAuth() - Autenticação e autorização
│   ├── useCurrency() - Formatação de moedas
│   ├── useTimeZone() - Conversão de fusos horários
│   └── useLanguage() - Internacionalização
├── Context API para estado global (Auth, Toast)
├── Componentes UI primitivos reutilizáveis
└── Separação clara: components/ | services/ | hooks/ | utils/

Backend Architecture

Clean Architecture com separação de concerns
├── Repository Pattern + Unit of Work
├── Service Layer para lógica de negócio
├── Minimal APIs (ASP.NET Core)
├── JWT Authentication com refresh tokens
├── Multi-tenant com TenantId em cada requisição
├── Soft delete para registros
└── Migrations automáticas com EF Core

Segurança

  • ✅ JWT tokens com validação completa em cada requisição
  • ✅ HTTPS enforcement em produção
  • ✅ Multi-tenant data isolation (zero vazamento de dados)
  • ✅ Input validation e sanitization
  • ✅ CORS configurado adequadamente
  • ✅ Webhook signature validation (WhatsApp)

Desafios Técnicos Superados

  • 1. Conversão de Timezone Implementei sistema completo de conversão entre UTC (backend) e timezone local (frontend), garantindo que agendamentos sejam precisos independente do fuso horário do tenant. Todos os cálculos consideram horário de funcionamento local.
  • 2. Independência Moeda-Idioma Criei sistema onde moeda e idioma são independentes, permitindo tenant brasileiro usar USD ou tenant americano usar BRL, com formatação correta baseada em locale. Utiliza Intl.NumberFormat para precisão.
  • 3. WhatsApp Menu Interativo Desenvolvi fallback inteligente quando dispositivo não suporta menus/botões, garantindo compatibilidade universal. Webhooks processam mensagens em tempo real com validação de assinatura.
  • 4. Detecção de Conflitos Implementei algoritmo que detecta conflitos de agendamento considerando duração de serviços e sobreposição de horários, validando disponibilidade antes de confirmar.
  • 5. Multi-Tenant Isolation Garanti isolamento completo de dados com validação em cada endpoint, impedindo acesso cruzado entre tenants. TenantId é extraído do JWT e aplicado em todas as queries automaticamente.
  • 6. Internacionalização Real Não é apenas tradução de strings - implementei formatação de moedas, datas e números que respeitam locale. Sistema carrega idioma da API e permite mudança dinâmica sem reload.

Destaques da API REST

A API foi desenvolvida com .NET 10 e PostgreSQL, implementando padrões modernos de arquitetura e documentação interativa completa com Scalar UI.

Endpoints Principais (40+)

  • Authentication & Users: Registro, login JWT, gestão de usuários por tenant
  • Tenants & Settings: Configurações por empresa (idioma, moeda, timezone, horário de funcionamento)
  • Customers: CRUD completo com endereço integrado e histórico
  • Pets: Cadastro com espécie, raça, peso, alergias e notas comportamentais
  • Services: Catálogo com preços, duração e status ativo/inativo
  • Appointments: Gestão completa com ações de status (confirmar, iniciar, concluir, cancelar)
  • Integrations: Configuração WhatsApp, webhooks e envio de mensagens
